# PocketPlan

PocketPlan is a lightweight student budget and expense tracker. Set a monthly spending limit, log expenses by category, watch the remaining balance update, and export your activity as CSV. It is responsive and stores all records locally in the browser with no account or backend.

## Features
- Monthly budget and spending progress
- Expenses with date, category, and amount
- Month-by-month records
- CSV export
- Local browser storage and responsive layout

## Run locally
Open `index.html` in a modern browser. No build tools or API keys required.

## Privacy
All expense and budget data is stored in the browser's local storage. Clearing browser data removes it, so use CSV export for a backup.
